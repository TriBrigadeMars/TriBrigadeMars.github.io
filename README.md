# Portfolio & Resume

Personal portfolio and resume website for **Mars Cruz, MPH, CHES**, built with React 19, Vite, Meta Astryx (`@astryxdesign/core`), and Tailwind CSS, prerendered to static HTML for GitHub Pages.

Live site: https://tribrigademars.github.io/

## Local development

You need **Node.js** and **Python 3** installed.

1. Install dependencies (first time only):
   ```bash
   npm install
   ```
2. Build the theme (if modified), compile Vite client/SSR bundles, prerender root HTML pages, and regenerate `llms-full.txt`:
   ```bash
   npx astryx theme build src/theme/cuDenverBrandTheme.ts --out src/styles/cu-denver-brand.css
   npm run build
   ```
   **Run `npm run build` after any change to `src/`** so `index.html`, `education.html`, `404.html`, `assets/app/`, and `llms-full.txt` stay current.
3. Check privacy, evidence, and machine-readable rules:
   ```bash
   npm run check
   ```
   Runs `facts.json` checks against all HTML pages and résumé, and fails if `llms-full.txt` is stale or `llms.txt` points at a missing file.
4. (Optional) Run the Vite development server:
   ```bash
   npm run dev
   ```

## Files

- `src/pages/`, `src/components/`, `src/data/`, `src/theme/` — React 19 + Meta Astryx source and CU Denver brand theme
- `index.html` — prerendered main portfolio and résumé page
- `education.html` — prerendered Interactive Educational Initiatives & Curriculum Lab page
- `404.html` — prerendered custom 404 page
- `llms.txt` — site manual for AI agents: what the site is, canonical facts, what not to infer
- `llms-full.txt` — the whole page as Markdown (generated by `npm run build`)
- `AGENTS.md` — instructions for coding agents working in this repository
- `facts.json` — privacy and evidence guardrails checked by `npm run check`
- `robots.txt`, `sitemap.xml` — crawl metadata
- `assets/resume.pdf` — downloadable resume
- `assets/app/` — compiled Vite CSS/JS hydration bundles (generated by `npm run build`)
- `favicon.ico`, `assets/favicon.svg`, `assets/apple-touch-icon.png` — browser and iOS icons
- `assets/og-image.png` — social share preview image
- `tailwind.config.js`, `vite.config.mts`, `package.json` — build configuration and scripts
