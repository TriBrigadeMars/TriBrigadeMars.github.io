# Portfolio & Resume

Personal portfolio and resume website for **Mars Cruz, MPH, CHES**, built with Tailwind CSS.

Live site: https://TriBrigadeMars.github.io

## Local development (Tailwind build)

This project uses a real Tailwind CSS build step instead of the CDN. You need **Node.js** installed (https://nodejs.org).

1. Install dependencies (first time only):
   ```
   npm install
   ```
2. Build the CSS and the machine-readable files:
   ```
   npm run build
   ```
   This generates `assets/styles.css` from `src/input.css` by scanning `index.html` for Tailwind classes, then regenerates `llms-full.txt` from `index.html`.
   **Run this after any change to `index.html`** so new classes and the agent-facing copy stay current.
3. Check the privacy and evidence rules:
   ```
   npm run check
   ```
   Runs `facts.json` against the page and résumé, and fails if `llms-full.txt` is stale or `llms.txt` points at a missing file.
4. (Optional) Auto-rebuild while you edit:
   ```
   npm run watch
   ```

## How to publish (GitHub Pages)

This folder is the root of the repository `TriBrigadeMars.github.io`.

1. Create a new repository on GitHub named **`TriBrigadeMars.github.io`** (public).
2. Copy the **contents of this folder** into the repository folder.
3. Commit and push (GitHub Desktop or `git push`).
4. Your site will be live at `https://TriBrigadeMars.github.io`.

## Files

- `index.html` — the website
- `llms.txt` — site manual for AI agents: what the site is, canonical facts, what not to infer
- `llms-full.txt` — the whole page as Markdown (generated by `npm run build`)
- `AGENTS.md` — instructions for coding agents working in this repository
- `facts.json` — privacy and evidence guardrails checked by `npm run check`
- `robots.txt`, `sitemap.xml` — crawl metadata
- `assets/resume.pdf` — downloadable resume
- `assets/styles.css` — compiled Tailwind CSS (generated by `npm run build`)
- `assets/favicon.svg` — browser tab icon
- `assets/og-image.png` — social share preview image
- `src/input.css` — Tailwind source styles
- `tailwind.config.js` — Tailwind configuration
- `package.json` — build scripts and dependencies
