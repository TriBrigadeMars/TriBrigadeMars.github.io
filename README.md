# Portfolio & Resume

Personal portfolio and resume website for **Mars Cruz, MPH, CHES**, built with Tailwind CSS.

Live site: https://TriBrigadeMars.github.io

## Local development (Tailwind build)

This project uses a real Tailwind CSS build step instead of the CDN. You need **Node.js** installed (https://nodejs.org).

1. Install dependencies (first time only):
   ```
   npm install
   ```
2. Build the CSS once:
   ```
   npm run build
   ```
   This generates `assets/styles.css` from `src/input.css` by scanning `index.html` for Tailwind classes.
3. (Optional) Auto-rebuild while you edit:
   ```
   npm run watch
   ```

**Important:** after you've run `npm run build` successfully and `assets/styles.css` exists, remove the temporary CDN fallback line from `index.html` (the line commented `<!-- TEMPORARY fallback ... -->`).

## How to publish (GitHub Pages)

This folder is the root of the repository `TriBrigadeMars.github.io`.

1. Create a new repository on GitHub named **`TriBrigadeMars.github.io`** (public).
2. Copy the **contents of this folder** into the repository folder.
3. Commit and push (GitHub Desktop or `git push`).
4. Your site will be live at `https://TriBrigadeMars.github.io`.

## Files

- `index.html` — the website
- `assets/resume.pdf` — downloadable resume
- `assets/styles.css` — compiled Tailwind CSS (generated by `npm run build`)
- `src/input.css` — Tailwind source styles
- `tailwind.config.js` — Tailwind configuration
- `package.json` — build scripts and dependencies
